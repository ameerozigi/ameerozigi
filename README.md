## Featured Projects

### 🦀 Rust / High-Performance Systems

- **CLOB Matching Engine** — Low-latency central limit order book targeting sub-500µs match latency. Built in Rust with Tokio async runtime, lock-free order queues, and price-time priority matching.
- **Async Tokio Order-Routing Pipeline** — High-throughput order routing pipeline with async I/O, backpressure handling, and deterministic execution ordering.
- **zkVM Circuit Toolkit** — Zero-knowledge virtual machine circuits (SP1/Risc0) for verifiable computation. Proves off-chain execution with on-chain verification.
- **AMM Liquidity Pool** — Constant-product AMM (x*y=k) in Rust with LP tokens, fees, slippage protection, and price impact calculation. [Repo](https://github.com/ameerozigi/amm-liquidity-pool)
